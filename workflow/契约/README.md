# 契约

每个模型任务契约都是 JSON，定义模型可见的输入产物、输出格式、输出模板和质量字段。Prompt Composer 只填入动态值，不在代码中复制输出字段结构。

`模式/` 保存运行产物的 JSON Schema，`模式/映射.json` 负责把产物名映射到具体 Schema。工具在以下边界执行 Draft 2020-12 校验：

- 运行配置、总纲、初始状态、故事单元、章节细纲和检查文件；
- 模型生成并准备落盘的状态事件与批次账本；
- 规划服务准备写入的故事单元和章节细纲。

Schema 负责类型、必填字段、枚举和基础结构。工具继续执行 Schema 无法表达的语义校验，例如“证据逐字存在于正文”“资源余额正确”“状态转换合法”“章节范围连续”。
