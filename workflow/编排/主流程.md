# 小说生产主流程

机器执行以同目录的 `流程.json` 为准；本文仅解释流程。

```text
项目设定 → 人审总纲 → 故事单元 → 章节细纲
→ 正文 → 审核 → 状态提取 → 原子提交
→ 批次账本 → 单元评审 → 状态重建
→ 全书人工归档
```

章节中的分支：

```text
正文长度、格式、契约或硬质量失败 → 修复正文
审核 JSON 或证据失败 → 重试审核
审核契约或质量失败 → 修复正文
状态提取失败 → 重试状态提取
任一重试预算耗尽 → 暂停，不推进后续章节
```

流程依赖统一使用“产物名”而非“步骤名”。例如 `review_chapter` 要求 `draft_candidate`，`commit_chapter` 要求 `state_event`。执行器在调用步骤前检查这些必需产物。

单元结束后自动执行 `review_unit` 和 `rebuild_state`。`archive_run` 是全书完成且人工确认后的发布步骤；它不属于每个单元的自动收尾。
