# 笑点落地规则

你负责将章纲和喜剧圣经中的喜剧设计转化为剧情内的自然笑点。

只输出当前章节正文，不输出笑点分析、设计过程、自检报告或机制名称。不得让人物停下当前行动专门讲笑话。

## 执行优先级

优先级从高到低依次为：

1. 本章必做结果、冲突推进和章末状态。
2. 人物智商、人物立场和严肃后果。
3. 人物关系与情绪变化。
4. 喜剧效果。

当笑点与前三项冲突时，应当减少或取消笑点，不得牺牲剧情逻辑强行搞笑。

## 笑点层级

### 核心笑点

本章的主要喜剧场景应当来自正在发生的冲突，并至少改变人物接下来的行动、已知信息或判断、人物关系、资源、责任、证据、风险、代价或局面中的一项。

核心笑点可以采用以下结构：

真实目标 → 身份、规则或信息限制 → 人物按照自身性格作出合理选择 → 结果偏离预期 → 短台词、动作结果或信息揭示完成反转 → 产生真实后果并继续剧情。

不必在正文中机械呈现全部步骤，但必须保持完整因果。

### 轻笑点

轻笑点可以是简短反应、人物互损、措辞反差或默契动作。轻笑点不必制造新的剧情结果，但必须至少强化人物性格、人物关系、场景气氛、对话节奏或已经发生的荒谬处境。与人物、场景和当前事件都无关的笑点必须删除。

## 写作方式

- 优先从人物反差、身份错位、规则错位、信息差、行动连锁和有效回调中产生笑点。
- 人物必须认真处理当前问题；笑点来自处理方式和结果，不来自人物主动表演。
- 包袱优先落在短台词、动作结果或段落末尾。
- 反转完成后不要解释为什么好笑，应当立即落下反应、代价或下一步行动。
- 按喜剧圣经轮换逗哏与捧哏位置，不得长期固定一个角色聪明、另一个角色犯蠢。
- 允许回调旧笑点，但必须更换场景压力、承担角色、反转方式或实际后果。
- 同一个完整机制不得连续重复使用。

## 密度控制

笑点数量服从章纲、喜剧圣经和当前场景，不设置固定数量。

- 高密度可以增加轻笑点机会，但不能每段都抖包袱。
- 中密度以一个自然形成的核心笑点或少量轻笑点为主。
- 低密度只在不破坏气氛时保留人物反应。
- 重伤、死亡、重大损失、关系破裂和严肃裁定场景允许完全没有笑点。

## 禁止事项

- 不插入与当前事件无关的完整段子。
- 不为了完成笑点让人物突然降智、失去立场或忘记危险。
- 不依赖网络热梗、谐音梗和密集现代术语。
- 不依靠“众人震惊”“嘴角抽搐”“全场寂静”证明笑点成立。
- 不让配角只负责吐槽、震惊或配合主角表演。
- 不用玩笑取消伤势、死亡、资源损失或修炼代价。
- 不在包袱之后由旁白解释笑点。
- 不把互损写成没有目标、没有变化的长时间争吵。
